# ストーリーバイブル

## シリーズの核

法律実務の「判断の怖さ」を、短編ミステリーの形でプレイヤーに体験させる。派手な犯罪ではなく、書類、時刻、供述、記録のわずかなズレを扱う。

## 主人公

若手弁護士。事務所内の異変を、証拠と時系列から整理する。正義感よりも、記録を丁寧に読む力を前面に出す。

## トーン

- 深夜の法律事務所
- 静かな緊張感
- 実務の言葉を使うが、プレイヤーが読み切れる短文にする
- 最終的には「法律家の判断」に戻す

## Case 02のテーマ

書面に「書くこと」と「書かないこと」。依頼者が不利な事実を消そうとする一方で、弁護士は提出書面としての正確さと戦略判断を分けて考える。

## Case 02のゲーム体験

- 開幕を3幕に分け、消えた一文、危険性、初動を短く提示する
- 調査で証拠を集める
- 争点整理で証拠同士の意味を結ぶ
- 対決で発言を詳しく聞き、証拠との矛盾を示す
- 最終推理で削除者、理由、機会、証拠を結論化し、成功/不成立の終幕を幕送りで読ませる

信用ゲージは、証拠の読み違いをゲーム上の緊張に変えるためのもの。難度は高くするが、焦点表示で次の行動は迷わせすぎない。

事件ファイルは単なる一覧ではなく、プレイヤーが証拠の意味を読み返す場所にする。証拠詳細には、関係する時刻、使う争点、提示・対決・最終推理での使い所を表示し、最終推理前の再確認をしやすくする。証言を崩す証拠には、証言録リンクとして崩す発言と現在の対決状態を残し、証拠詳細から証言録へ戻って読み直せるようにする。照合ノートでは証拠2点を並べ、同じ時刻、同じ争点、同じ論点にかかるかを読ませる。記録相関図では、選んだ証拠が時系列、争点、対決、最終推理のどこに刺さるかを俯瞰し、関連証拠へ移って読み比べられるようにする。
時系列タブは、時刻の羅列ではなく、記録がどの疑いを外し、どの反論に使えるかを読む場所にする。印刷、来訪、保存、説明準備がどの証拠で裏付けられるかを、事件ファイル内で確認できるようにする。
証言タブは、対決の結果を事件ファイルへ戻す場所にする。元の発言、追及後の補足、当てる記録、現在の対決状態を並べ、プレイヤーが証拠一覧と証言送りを往復しなくても推理の材料を読み返せるようにする。
対決中や最終推理中は、画面を移動せずに証拠詳細を一時表示できるようにする。推理の流れを切らず、証拠の時刻、説明、使う争点をその場で読み返すための補助線にする。
論点ボードは、集めた証拠を削除者、理由、機会、決め手へ置き直す作業面にする。正解をそのまま渡すのではなく、どの論点が成立し、どこがまだ材料不足かを見せる。
場所移動は単なるメニューではなく、探索計画を立てる画面にする。現在地、調査可、前提待ち、確認済みを分け、次に触れる調査項目と証拠の集まり具合を読めるようにする。
調査は、選択肢リストを読むだけにしない。現場画像上の調査ポイントで「どこを見るか」を選ばせ、同じ内容をリストでも読めるようにして、視覚的な探索と記録読解を両立させる。現場メモでは、その場所で何が解け、何がまだ前提待ちかを短く読み返せるようにする。証拠を見つけた瞬間は、入手パネルで画像、概要、次に読む争点を返し、証拠が事件ファイルへ加わった手応えを出す。

会話は、話題リストではなく人物ごとの供述メモとして扱う。顔、役割、人物要約、聞ける話題数を先に見せ、どの人物からどの論点を聞くのかをプレイヤーが整理して選べるようにする。
会話後は、直近の供述を消費済みにするだけで終わらせない。供述メモ更新として、次に聞ける話題と証拠で詰められる候補を返し、会話から提示・事件ファイルへ自然につなげる。

証拠提示は、正解の反応を選ぶだけのボタンにしない。人物と証拠を自分で結び、外したら信用が下がることで、記録の読み違いがそのままゲーム上の緊張になる。
提示前には、相手の言い分、証拠の読み方、突きつける問いを並べ、プレイヤーが「なぜこの証拠をこの人物に当てるのか」を自分で確認できるようにする。弱い組み合わせもただ失敗させず、どの前提が足りないかを読ませる。
提示成功後は、演出だけで流さない。発言、証拠、認めた点、次の一手を短い反応分析として残し、プレイヤーが「何を崩したのか」を手元で読み返せるようにする。

相談メモは、正解を渡す画面ではなく、観察、照合、具体操作の順に読み筋を整える補助線にする。プレイヤーが証拠を選ぶ余地を残すため、最初から全ヒントを開示しない。関連証拠はチップから事件ファイルの該当記録へ直接戻れるようにし、迷った時に読むべき記録へ復帰する速度を上げる。

コマンド表示は、次に何を押せば正解かを教えるリストではなく、今どの作業面が使えるかを読む進行盤にする。現在、実行可、材料不足、整理待ちを短く見せ、押せる見た目なのに進まない状態を避ける。

対決支援は、発言、証拠、時刻を横に置いて比較するための作業机として扱う。答えを誘導しすぎず、プレイヤーが記録の読み方を変える瞬間を作る。
照合レーンでは、発言の主張と記録の示す事実を短く言い換え、どの比較軸で読むべきかを明示する。プレイヤーに正解を丸出しにするのではなく、「権限ではなく機会」「怖くなった時期」のような読み替えを促す。
提出前チェックは、矛盾を示す直前の小さな息継ぎにする。発言、証拠、前提、照合を4項目で見せ、当て所がずれているときは信用を落とす前に「どこを読み直すべきか」をプレイヤーが判断できるようにする。
対決の証言は、一覧を眺めるだけではなく、1件ずつ送りながら読む。前後移動、確認済みマーカー、証拠提示を同じ流れに置き、証言の揺れを自分で探す感覚を強める。
証言ごとの状態表示は、正解を渡すためではなく、今すべき行為を読むためのUIにする。背景確認、ゆさぶり、前提不足、提示可能、突破済みを切り替え、プレイヤーが「なぜ今この証拠を示せるのか」を理解できるようにする。
証言読み筋は、発言の芯、読む記録、次の操作を短く並べる手控えにする。正解を丸出しにするのではなく、相手が何を言い切ったのか、その言葉をどの記録へ寄せるのかをプレイヤーが確認できるようにする。
崩し順メモは、対決の2段階構造をプレイヤーの手控えとして残す。どの矛盾が前提待ちで、どれが指摘可能で、どれを突破済みかを見せ、証言へ戻って読み直す動きを自然にする。
ゆさぶり反応は、証言者の感情を派手に見せるためではなく、発言を証拠に当てられる形へ絞り込むために使う。押した後は候補証拠と理由を返し、プレイヤーが「発言のどこが記録へ接続したか」を読めるようにする。誤った指摘も、単なる失点ではなく、どの記録へ戻るべきかを返す。
誤提示後の候補記録は、答えを読ませるためではなく、証言と記録のどちらを読み違えたかを確認する入口にする。候補記録を開いて時刻や記載内容を読み返し、再度同じ証言へ戻れるテンポを保つ。
証言更新は、詳しく聞いた瞬間の成果を一時演出で終わらせず、対決中の手控えとして残す。元の発言、追及後の補足、次に当てる記録を同じ場所に置き、証言が証拠へ近づいたことをプレイヤーが読み返せるようにする。
証言送りと論点移動のキーボード操作は、画面説明を増やさずにテンポだけを上げるために使う。セレクト操作中は発火させず、プレイヤーが証拠や結論を選んでいる時の意図を優先する。
現在の焦点は、プレイヤーに答えを渡す場所ではなく、迷ったときに次の操作へ戻る足場にする。推奨コマンドと相談メモを並べ、調査、提示、整理、対決、推理のどこへ戻ればよいかを短く示す。

最終推理の誤答は、即座に物語を閉じるのではなく、法律家が結論を出す前に論点を差し戻す感覚にする。信用は下がるが、どの論点を読み直すべきかを返し、記録へ戻って修正できるようにする。
反論ステージで誤答したときは、再検討メモで残った反論、弱い組み合わせ、読み直す記録を見せ、プレイヤーが正しい根拠証拠へ戻って自分で筋を組み直せるようにする。
最終推理では、削除者、理由、機会、決め手を言い当てるだけで終わらせず、それぞれに根拠証拠を添える。プレイヤーが「なぜその結論になるか」を最後に自分で提出する構造にする。
最終推理の画面は、相手の反論を1つずつ崩す連続ステージとして扱う。論点ごとに「相手の言い分」「こちらの筋」「突きつける証拠」を並べ、最後に全体の結論を出す。
各論点では、結論と証拠を選ぶだけで自動的に進ませず、一度突きつけて反論が崩れたかどうかを返す。成立した論点は次へ進め、残った論点はどの記録へ戻るべきかを短く示す。
反論照合は、プレイヤーが選んだ結論と証拠を提出前に読み直すための作業面にする。相手の残る反論、証拠が示す事実、照合結果を並べ、正解の丸暗記ではなく「この証拠でその結論を支えられるか」を判断させる。
反論設計メモは、プレイヤーが選んだ結論と根拠証拠を4論点分まとめる最後の手控えにする。論点を移動しながら、どこが未完成で、どこが再検討なのかをすぐ読み返せるようにする。
最終証拠チェーンは、選んだ証拠を時刻や争点に置き直す最後の作業面にする。単発の正解確認ではなく、来訪、更新、説明準備が一本の流れとして読めるかをプレイヤー自身に確認させる。

ログは単なる進行記録ではなく、プレイヤーが発言の温度、取得した証拠、場所の文脈を読み返すための手控えにする。記録を読み返す行為そのものを、法律ミステリーのゲームプレイに含める。証拠付き、追及/突破、対決、推理で絞り込めるようにし、プレイヤーが必要な調書へ戻る速度を上げる。
再開メモは、セーブされた直近の行動を通常画面に残すための小さな手控えにする。長いログを開かなくても、最後に何を確認したか、どの証拠が関係したかを読み、必要ならすぐログへ戻れるようにする。

事件解剖はクリア後の答え合わせであり、同時に証拠の読み方を定着させる報酬画面にする。削除者、理由、機会、決め手を並べるだけでなく、どの証拠がどの役割を持ったかまで見せる。

制作資料は、事件を解いた後に脚本意図を読める余韻として置く。通常プレイの説明ではなく、テーマ、誤誘導、対決設計、実務要素、次回への種を短く残す。

カットインは、証拠読解の節目を知らせる短い演出に留める。感情を煽るためだけではなく、追及、突破、信用低下、結論成立の状態変化をプレイヤーに即時に伝える。

インパクト演出は、正しい証拠を突きつけた瞬間の手応えとして使う。長く読ませる情報は記録照合パネルへ渡し、ここでは「選択が刺さった」ことだけを強く返す。

記録照合演出は、正解した瞬間に「何が何と食い違ったのか」を短く見せるための補助にする。発言、照合結果、証拠チップを並べ、プレイヤーが自分の選択で記録を動かした感覚を得られるようにする。
追及メモは、記録照合の余韻を通常画面へ残すための短い手控えにする。正しい提示、整理、対決突破が連続した時に、プレイヤーが「今どこまで崩したか」を見失わないようにする。

人物表情差分は、証拠読解の手応えを補強するために使う。通常、追及、突破、信用低下で表情を変え、派手な演出よりも「記録を突きつけられた反応」が読めることを優先する。

効果音は、画面の情報量を増やさずに状態変化を伝えるための補助にする。証拠取得、追及、突破、信用低下で音の輪郭を変え、深夜の法律事務所という静けさを壊さない短さに留める。

開幕/終幕は、長い説明を一度に置かず、プレイヤーが一幕ずつ事件の意味を受け取れるテンポにする。開幕はスキップ可能にし、終幕は真相、理由、提出判断の順に法律家の判断へ戻す。

## 禁止事項

- 実在事件や実在依頼者を直接モデルにしない
- 実務上の断定をゲーム内の一般論として広げすぎない
- 法律用語だけで真相が決まる構成にしない
