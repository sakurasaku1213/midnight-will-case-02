# 制作仕様書

## 目的

10分前後で遊べる、法律事務所を舞台にした短編ミステリーADVを作る。前作のプレイヤーが迷わず入れるよう、調査、証拠取得、会話、証拠提示、最終推理の流れを維持する。

## 技術方針

- React + TypeScript + Vite
- DOM UI中心のADV
- シナリオ分岐は `data/episode-02.json`
- 保存対象は `GameState` のみ
- 画像や音声は `public/assets` に置き、データ側から安定した `assetKey` で参照する
- 実ファイルのパス、素材カテゴリ、生成ブリーフは `src/game/assets.ts` の `assetRegistry` に集約し、起動時に既存UI用の画像パスへ解決する

## コア導線

1. 複数幕の開幕で、消えた一文の問題点と初動を読む
2. 場所を移動する
3. 調べる、話す、見せるで証拠とフラグを集める
4. 証拠2点を選ぶ争点整理で、証拠同士の関係を説明する
5. `final_unlocked` と `analysis_complete` が立ったら対決へ進む
6. 対決で発言を詳しく聞き、証拠の矛盾を2段階で示し、`hearing_cleared` を立てる
7. 最終推理4問に正解すると複数幕の成功エンド、誤答時は設問別レビューを出して信用を下げ、信用切れで複数幕の推理不成立エンド
8. 成功後に `case_cleared` が立ち、クリア後の事件解剖で真相と証拠の役割を読み返せる

## コマンド導線

- コマンドボタンには「現在」「実行可」「証拠待ち」「材料不足」「整理待ち」などの短い状態を表示する
- disabled 表示と `setMode` の解放条件は同じ前提を使い、押せる見た目なのに遷移しない状態を作らない
- `整理する` は証拠2点以上、`見せる` は証拠1点以上、`対決` は提示と争点整理、`推理する` は対決突破、`事件解剖` は成功後に解放する
- モバイルでもコマンド内の状態チップと短い理由が横にはみ出さないようにする

## 開幕/終幕

- `openingScenes` で導入を3幕に分け、違和感、危険性、初動を順に見せる
- `endings.success.scenes` と `endings.failure.scenes` で結末を複数幕に分ける
- 幕はスキップ可能で、開幕中でも調査開始できる
- 幕データは仮画像パス、話者、トーンを持ち、後から高品質画像に差し替えられる

## 場所移動

- 移動画面では4つの場所をカードで表示し、現在地、調査可、前提待ち、確認済みの状態を分ける
- 各カードには場所画像、次に触れる調査項目、未確認数、取得済み証拠数を表示し、探索の次手を判断できるようにする
- モバイルでは移動カードを縦積みにし、場所画像と進捗チップが横にはみ出さないようにする

## 事件ファイル

- 証拠: 取得済み証拠、重要マーク、仮画像、詳細説明
- 人物: 登場人物の役割と要約
- 時系列: 取得済み証拠で裏付けられた時刻だけを表示し、時系列解析で各時刻の証拠、崩す主張、使う場面を確認できるようにする
- 証言: 対決で詳しく聞いた発言を、元の発言、追及後の補足、当てる記録、対決状態ごとに読み返せるようにする
- 論点: 削除者、理由、機会、決め手を、入手済み証拠と進行フラグで「材料不足」「調査中」「成立」に分けて表示
- 証拠詳細: 選択中の証拠について、関連時刻、使用する争点、提示・対決・最終推理で使う場面を表示
- 証拠詳細には証言録リンクを置き、その証拠で崩す発言と対決状態を表示して、証言録へ戻れるようにする
- 照合ノート: 選択中の証拠と別の取得済み証拠を並べ、共通する時刻、争点整理、論点を表示
- 記録相関図: 選択中の証拠が時刻、争点、対決、最終推理、提示のどこに使われるかをまとめ、関連証拠へ移れるようにする
- 対決と最終推理では、選択中の証拠から一時的な証拠詳細を開き、画面を離れずに時刻と争点を読み返せる

## 調査ポイント

- `inspect` では、現場画像の上に調査ポイントを番号付きで表示する
- 下部には同じ行動を詳細リストとして表示し、画像上のポイントだけに頼らず読めるようにする
- モバイルでは画像上のラベルを番号中心に圧縮し、長い説明はリスト側で読む
- 現場メモで、次に調べる項目、調査可/確認済み/前提待ち数、この場所で取得した証拠をまとめて表示する
- 調査ポイントは `Location.actions` から生成し、後から高品質な背景画像に差し替えてもUI構造を保つ
- 証拠を取得した時は、短い通知に加えて、証拠画像、概要、次に読む争点、事件ファイルへの導線を持つ入手パネルを表示する

## 会話

- `talk` では人物ごとに供述カードをまとめ、顔、役割、要約、聞ける話題数を表示する
- 話題は番号付きのボタンとして並べ、会話を実行する前にログ/要点を読めるようにする
- 会話を実行した直後は、直近の供述、次に聞ける話題、証拠提示で詰められる候補を追及メモとして表示する
- モバイルでは人物カードと話題ボタンを縦積みにし、長い要点でも横スクロールを出さない

## 証拠提示

- 「見せる」では、人物と証拠を選んで提示する
- 正しい組み合わせだけをボタンで表示せず、選択中の人物要約と証拠詳細を見せる
- 選択中の人物と証拠から、相手の言い分、証拠の読み方、突きつける問いを提示前の圧力ボードとして表示する
- 圧力ボードでは、詰め筋がある組み合わせと弱い組み合わせを区別し、外す前に読み直す余地を残す
- 提示成功後は、発言、証拠、認めた点、次の一手を4段階の反応分析として通常画面に残す
- 誤提示時は信用を1つ下げ、事件ファイルと証拠の役割を見直す導線にする
- 成功提示後は証拠選択を外し、同じ提示の連打で誤提示になりにくくする

## 相談メモ

- `consult` モードは通常コマンドには並べず、「現在の焦点」から開く
- サイドバーの「現在の焦点」には次の一手カードを置き、推奨コマンド、理由、相談メモへの導線を常時確認できるようにする
- 進行フラグに応じて、現在の読み筋、段階ヒント、関連証拠、次の行動を表示する
- ヒントは初期表示を1段階に抑え、「もう少し踏み込む」で観察、照合、具体操作の順に開示する
- 関連証拠チップは取得済み証拠だけを表示し、未取得証拠の名称を先に見せない
- 関連証拠チップを押すと、事件ファイルの該当証拠詳細へ直接移動する
- 相談は信用を下げない支援導線だが、推理や証拠提示の正誤判定は既存ルールのまま維持する

## クリア後レビュー

- 成功エンド後に `case_cleared` を保存し、コマンドの「事件解剖」を解放する
- 事件解剖では、削除者、理由、決め手、証拠の鎖、提出前の判断メモを表示する
- レビュー内の証拠チップは `episode.evidence` を参照し、後から画像を差し替えても反映される
- 事件解剖から制作資料へ進める
- 失敗エンドでは解放せず、事件ファイルと推理見直しに戻す

## 制作資料

- `productionMaterials` はクリア後専用の脚本メモとして扱う
- テーマ、誤誘導、対決設計、実務要素、素材差し替え、次回への種を短いカードで表示する
- 素材差し替え計画では、場所、証拠、人物、開幕/終幕CGのスロット数と `assetRegistry` の manifest 件数を表示する
- 通常コマンドには並べず、事件解剖から入るボーナス導線にする

## 対決支援

- 対決では証言を1件ずつ送るボードを表示し、前後の証言へ移動できる
- 対決では左右キーでも証言を送れるようにし、証拠セレクトなど操作中のフォームではショートカットを発火させない
- 証言マーカーで現在位置と「詳しく確認済み」状態を読めるようにする
- 証言ごとに「背景証言」「要ゆさぶり」「前提不足」「提示可能」「突破済み」の状態を表示する
- 証言カードには証言者ポートレートと心理読み取りを表示し、ゆさぶり前後の狙いを明確にする
- 証言カード直下に証言読み筋を置き、発言の芯、読む記録、次の操作を表示する
- 対決進行カードで、現在の証言、読むべき記録、選択中証拠の噛み合わせを見せる
- 対決では、選択中の発言、示す証拠、証拠に関係する時系列を同じ画面内に並べる
- 対決支援には照合レーンを置き、比較軸、発言の主張、記録の示す事実、照合結果を短く並べる
- 正解を直接示さず、プレイヤーが「発言のどの部分」と「証拠のどの時刻・内容」が食い違うかを比較できるようにする
- 対決支援には提出前チェックを置き、発言、証拠、前提、照合の4項目から「提出可」「照合外」「要ゆさぶり」「前提待ち」を読めるようにする
- 対決には崩し順メモを置き、2段階の矛盾について前提待ち、指摘可能、突破済みを表示し、カードから対応する証言へ戻れるようにする
- 詳しく聞いた発言は確認済みとして表示し、対決の進捗をカード上で読めるようにする
- 詳しく聞いた発言には証言更新パネルを残し、元の発言、追及後の補足、次に当てる記録を同じ画面で読み返せるようにする
- 誤った証拠を提示したときは、外れた理由だけでなく、その証言で読み直すべき候補記録を表示し、証拠詳細をその場で開けるようにする
- 詳しく聞いた直後は、押した発言、引き出した反応、次に読む記録、次に当てる証拠候補とその理由を一時パネルで表示する
- 誤った矛盾指摘では、弱い理由と次の見直し先を一時パネルで返し、信用低下だけで終わらせない

## 最終推理レビュー

- 最終推理では各設問について、結論の選択肢と、その結論を支える根拠証拠を選ぶ
- 最終推理は、削除者、理由、機会、決め手を1論点ずつ進める反論ステージとして表示する
- 最終推理では左右キー、Home、Endで論点ステージを移動できるようにし、セレクト操作中はショートカットを発火させない
- 各論点では、相手の反論、こちらの筋、突きつける結論、根拠証拠を同じ画面で確認する
- 選択中の結論と根拠証拠は、反論照合パネルで「相手の残る反論」「選択中の証拠読み」「照合結果」として事前に読めるようにする
- 各論点は「突きつける」を押した時点で中間判定を出し、反論が崩れたか、どの観点がまだ弱いかを返す
- 選択中の結論と根拠証拠は反論設計メモに要約し、4論点が提出できる鎖になっているかを即時に確認できるようにする
- 選択した根拠証拠は最終証拠チェーンに並べ、削除者、理由、機会、決め手が一本の流れになるかを確認できるようにする
- 根拠証拠は取得済み証拠だけから選ばせ、未取得証拠を先に見せない
- 結論と根拠証拠の両方がそろうまで提出ボタンは押せない
- 最終推理の誤答は即失敗にせず、設問ごとに「成立」「再検討」を表示する
- 誤答時は信用を1つ下げ、削除者、理由、機会、決め手のどの論点を見直すべきかだけを返す
- 反論ステージの誤答時は再検討メモを表示し、残る反論、弱い組み合わせ、読み直す記録を示して、根拠証拠をその場で開けるようにする
- 正解そのものは明示せず、事件ファイルと時系列を読み返して再挑戦する導線にする

## ログ

- 行動ログとは別に、会話・調査・対決・推理の詳細履歴を `GameState.history` に保存する
- 詳細履歴には、話者、場所、モード、本文、演出トーン、取得証拠を持たせる
- コマンド欄には再開メモを置き、最新の詳細履歴、自動保存状態、関連証拠、ログへの導線を表示する
- ログ画面では最新順のカードとして表示し、プレイヤーが証言や反応を後から読み返せるようにする
- ログ画面には、全件、証拠付き、追及/突破、対決、推理の絞り込みを置き、必要な記録へ戻りやすくする

## カットイン演出

- 成功、追及、信用低下、推理成立/不成立の状態変化で短いカットインを表示する
- カットインは操作を塞がず、通常画面を読み続けられるよう900ms程度で消える
- 正しい証拠提示、争点整理、対決矛盾の成立時は、記録照合パネルの前に「異議あり」「突破」のインパクト演出を一瞬だけ表示する
- `prefers-reduced-motion` に従い、低モーション環境では強い移動アニメーションを使わない

## 記録照合演出

- 証拠提示成功、争点整理成功、対決での矛盾成立時に、短い記録照合パネルを表示する
- 記録照合パネルは、発言または問い、照合結果、使った証拠チップを並べて表示する
- 話者IDと演出トーンから人物表情差分を選び、追及、突破、信用低下の状態変化を短い人物カットで見せる
- 通常のカットインより長く残し、プレイヤーが証拠の噛み合わせを読める時間を確保する
- 正しい証拠提示、争点整理、対決突破の後は、直近の突破点を追及メモとして短く残す
- 保存データには含めず、一時UIとして扱う

## 効果音

- 外部音声素材を使わず、Web Audioで短い効果音を生成する
- 証拠取得、追及、突破、信用低下、選択操作にそれぞれ短い音を割り当てる
- トップバーから効果音のオン/オフと音量を変更でき、設定はlocalStorageに保存する

## 実装境界

- `src/app`: 画面構成、プレイヤー操作
- `src/game`: 型、状態更新、保存、信用ゲージ、分岐条件
- `data`: 事件の内容
- `docs`: 仕様、脚本、QA
