# 一画面固定レイアウト仕様書（縦長解消）

ページ全体の縦スクロールを廃止し、PC・スマホとも**常に1画面（100dvh）に収まる**ゲーム画面へ再設計するための正。`docs/ui-restyle-spec.md` のレイアウトに関する記述（特に §3 の画面配置）より本書が優先する。色・字・様式のトークンは引き続き `docs/design-system.md` を正とする。

## 1. 診断（2026-06-12 実測。再設計の根拠）

デスクトップ 1278×910 で計測した結果:

| 領域 | 実測高さ | 評価 |
| --- | --- | --- |
| ページ全長 | **4030px（ビューポートの4.4倍）** | 問題の本体 |
| `.topbar` | 155px | 過大。48〜56pxへ |
| メイン列（`.scene-panel` 543px ＋ `.work-panel` 292px） | 約835px | **既に1画面に収まっている** |
| `.command-panel`（右サイドバー） | **3811px** | ページ全長の決定要因 |

サイドバー3811pxの内訳（11枚の縦積み）: `command-grid` 687 / `case-focus` 72 / `case-director` 506 / `chapter-guide` 318 / `case-map` 562 / `soundtrack-panel` 287 / `status-strip` 49 / `credibility-risk-card` 198 / `theory-progress-card` 239 / `session-bookmark` 405 / `progress-trail` 333。

つまり縦長の原因はモード本体ではなく、**補助カードを全部同時に「積んで」いること**。再設計の核心は「積む → 切り替える」への転換と、ページスクロールの禁止。

## 2. 設計原則

1. **ページはスクロールしない**: `html, body, #root` と `.app-shell` は `height: 100dvh; overflow: hidden`（`dvh` でモバイルのアドレスバー伸縮に追従）。スクロールが発生してよいのは本書で指定した内部領域のみ
2. **常時可視は3つだけ**: ステージ（絵と台詞）/ コマンド / 信用・状態。それ以外の補助情報は「切り替えて見る」
3. **補助カードは廃止せず移設**: 11枚のカードは情報として有効。タブ（PC）とボトムシート（スマホ）に移し、**同時表示は常に1枚**
4. **機能・フラグ・保存・文言は不変**: 変えるのは配置とスクロール構造だけ。disabled 条件・状態チップ文言・QA済みの導線は維持

## 3. デスクトップレイアウト（>820px）

```text
┌─────────────────────────────────────────────┬──────────────┐
│ topbar（48px: 話数チップ・題字・⚙設定・リセット）│              │
├─────────────────────────────────────────────┤  dock 380px  │
│ stage（clamp(240px, 38dvh, 420px)）          │ ┌──────────┐ │
│  背景画像full-bleed＋立ち絵＋台詞オーバーレイ   │ │コマンド   │ │
├─────────────────────────────────────────────┤ │2列グリッド│ │
│ work-surface（残り全部・内部スクロール）       │ ├──────────┤ │
│  現在モードの作業面（調査/会話/対決/推理…）    │ │信用ゲージ │ │
│                                             │ ├──────────┤ │
│                                             │ │手控えタブ │ │
│                                             │ │(1枚表示・ │ │
│                                             │ │内部scroll)│ │
└─────────────────────────────────────────────┴──────────────┘
```

- グリッド定義: `grid-template-rows: var(--h-topbar) 1fr; grid-template-columns: minmax(0, 1fr) 380px`。左セル内は `flex-direction: column` で stage（固定高）＋ work-surface（`flex: 1; min-height: 0; overflow-y: auto`）
- スクロール領域は `work-surface` と「手控えタブのパネル部」の2箇所のみ。スクロールバーは design-system の細身様式

### 3.1 topbar（155px → 48px）

- 残すもの: 話数チップ（`CASE 02`）、題字（`--text-m` 程度に縮小、明朝のまま）、設定ボタン（⚙）、リセット
- `subtitle`（提出前夜、削除された…）はタイトル画面にあるため削除。`AudioControls` のスライダー・演出テンポは **⚙ポップオーバー**へ移設（`SoundtrackPanel` の試聴等は手控えタブ「音響」へ）
- 受け入れ基準: topbar 実測高 ≤ 56px、機能（音量・テンポ・リセット）は全て到達可能のまま

### 3.2 stage（scene-panel の置き換え）

現状の「テキストカード＋画像カードの横並び」をやめ、**画像の上に台詞を重ねる**ADV標準形へ:

- 背景: 場所画像 or 幕間CGを `object-fit: cover` でステージ全面に。下1/3に `--noir-night-deep` への縦グラデスクリム
- 立ち絵: 話者がいる時、右端に高さ90%で配置（バストアップ素材1024×1536）。`tone` による表情差分・カットイン演出は現行ロジックのまま
- 台詞ボックス: ステージ下部オーバーレイ。話者名プレート（琥珀罫）＋本文（最大3行、`-webkit-line-clamp: 3`。あふれる場合は「▼続き」で全文をその場で展開し、展開分だけ台詞ボックス内をスクロール）
- 開幕・終幕の幕リスト（01/02/03…）と幕送りボタンは台詞ボックス右肩のコンパクトチップへ
- ラベル（場所名・時刻）は左上の小さな調書タグ
- 受け入れ基準: stage 実測高が `clamp(240px, 38dvh, 420px)` に一致し、画像・立ち絵・台詞・幕送りがすべてステージ内に収まる

### 3.3 work-surface（モード作業面）

- 各モードパネル（`MovePanel` / `InspectPanel` / `TalkPanel` / `PresentPanel` / `AnalysisPanel` / `HearingPanel` / `DeductionPanel` / `CaseFilePanel` / ログ / 事件解剖 / 制作資料）は中身を変えず、この領域に流し込む
- 領域は `overflow-y: auto`。**ページではなくこの面だけ**がスクロールする
- 主操作（対決の証言送り＋証拠セレクト＋提出ボタン、最終推理の結論セレクト＋突きつけるボタン）は各パネルの先頭側に置き、初期表示で見えていること
- 補助サブパネル（対決の崩し順メモ・照合レーン・提出前チェック、推理の反論設計メモ等）は `<details>` アコーディオン化し初期は閉じる（任意。S8）
- 受け入れ基準: どのモードでもページ `scrollHeight === innerHeight`。作業面内部のスクロールのみ許容

### 3.4 dock（サイドバーの再構成）

上から順に、固定→固定→可変:

1. **コマンドグリッド（固定）**: 10コマンドを2列×5行のアイコン＋短ラベル（高さ目安 ~240px）。状態チップは右肩の小ドット＋ホバー/フォーカスで理由ツールチップ。「現在」は琥珀点灯。disabled 条件・文言は不変
2. **信用・状態ストリップ（固定）**: 信用5灯ゲージ＋証拠数＋現在地（`status-strip` と `credibility-risk-card` の要約行）。高さ目安 ~56px
3. **手控えタブ（可変・内部スクロール）**: 旧サイドバーカードを5タブへ移設。同時表示は1枚:

| タブ | 移設する旧カード |
| --- | --- |
| 焦点（既定） | `case-focus`＋`case-director`＋`chapter-guide` |
| 章 | `case-map`＋`progress-trail` |
| 論点 | `theory-progress-card` |
| 記録 | `session-bookmark`（再開メモ） |
| 音響 | `soundtrack-panel`（試聴・レイヤー表示） |

- `credibility-risk-card` の詳細文は「焦点」タブ内へ（要約はストリップに常時）
- 受け入れ基準: dock 全体が `100dvh - topbar` に収まり、タブパネル部だけがスクロールする。各タブの情報・導線（相談メモへのジャンプ等）は全て従来どおり到達可能

## 4. モバイルレイアウト（≤820px）

```text
┌──────────────────────────────┐
│ topbar 44px（チップ・題字・⚙） │
├──────────────────────────────┤
│ stage 34dvh                  │ 画像＋立ち絵＋台詞オーバーレイ
├──────────────────────────────┤
│ work-surface（1fr・内部scroll）│ 現在モードの作業面
├──────────────────────────────┤
│ dock 64px（横スクロールチップ）│ コマンド10個＋[手控え]
└──────────────────────────────┘
```

- `grid-template-rows: 44px 34dvh minmax(0, 1fr) 64px`
- **dock は画面下固定**（ゲーム機のボタン列の位置）。アイコン＋2文字ラベルのチップを横スクロール1行で並べ、現在モードは琥珀点灯。末尾に「手控え」ボタン
- **手控え＝ボトムシート**: 「手控え」タップで下から70dvhのシートが出て、§3.4 と同じ5タブを表示。シート内のみスクロール。背面タップ・閉じるで戻る。`role="dialog"`、開いている間は背面スクロールなし（そもそもページは固定）
- 台詞は2行クランプ＋タップ展開。立ち絵はステージ右に高さ100%・透かし気味（本文の可読性優先）
- 効果音・テンポ・リセットは topbar の⚙ポップオーバーに集約
- 受け入れ基準: 390×844 で全モードのページ `scrollHeight === innerHeight`。横スクロールは dock のチップ行のみ。既存QA「はみ出さない」系を全て維持

## 5. 演出の位置調整

- カットイン・インパクト演出・記録照合パネルは `position: fixed` のステージ中央オーバーレイへ（ページスクロールが無くなるため、現在の文書フロー内表示だと作業面スクロール位置によっては見えない）
- 証拠入手パネル・反応分析などの一時パネルは「台詞ボックスの直上にトースト的に重ねる」を基本にし、操作を塞がない現行方針を維持
- `prefers-reduced-motion` の扱いは現行どおり

## 7. やらないこと

- 補助カードの情報削除（移設のみ。文言・データは変えない）
- モード本体の機能変更、フラグ・保存形式の変更
- `AppShell.tsx` の大規模分割（区画単位のマークアップ修正は可）
- 新規依存の追加（タブ・ポップオーバー・ボトムシートは自前実装。`<details>`/`<dialog>` などの標準要素を優先）
