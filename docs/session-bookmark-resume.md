# Session Bookmark Resume

The sidebar resume card now works as a compact return-to-play surface instead of a passive log shortcut.

- Shows the current location and the recommended command from the same consultation logic used by the focus card.
- Summarizes the next action with the current guide title and summary.
- Displays compact progress for evidence, hearing contradictions, and theory issues.
- Keeps both recovery routes available: open the history log or jump directly to the next recommended mode.
