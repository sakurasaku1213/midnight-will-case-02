# Case 02「消えた準備書面」アウトライン

## 位置づけ

`午前0時の遺言書` の第2話。前作が「自筆証書遺言の原本が消える」という物理的な消失を扱ったのに対し、今作は「提出前の準備書面から一文が消える」事件を扱う。

## あらすじ

翌朝10時、重要な民事事件の準備書面を提出する予定だった。深夜の最終確認で、主人公は旧版にはあった一文が最新版から消えていることに気づく。

その一文は依頼者にとって有利にも不利にもなり得る危うい記載だった。誰が、なぜ、提出直前にその一文を消したのかを、印刷履歴、ファイル更新履歴、メール下書きから解く。

## 真相

- 削除した人物: 依頼者B
- 理由: 問題の一文の裏付けが薄く、相手方から反撃材料として使われる可能性に気づいたため
- 機会: 小野寺のログイン状態で残っていた会議室の共用PC
- 決定的証拠: メール下書き、来訪カード履歴、ファイル更新履歴の組み合わせ

## ミスリード

- 23時台のプリンタ履歴により、事務員Aが疑われる
- 事務員Aは実際に一度事務所へ戻っている
- ただし印刷したのは別件の書面
- ログイン名だけを見ると主任弁護士が編集したように見える
- 赤入れメモは削除指示ではなく、提出前の再判断メモにすぎない

## 最終推理

1. 誰が削除したか
2. なぜ削除したか
3. どの機会で削除できたか
4. どの証拠の組み合わせで説明できるか

## ラストの余韻

「不利な事実を消しても、事件が強くなるわけではありません」

ただし、書面から一文を消すことが常に悪いわけではない。問題は、誰が、どの判断で、何を隠そうとしたのか。
